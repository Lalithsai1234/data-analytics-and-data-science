# data-analytics-and-data-science

![Animated Header](assets/animated-header.svg)

A curated collection of educational Python exercises, small projects, and practice problems focused on fundamentals, object-oriented programming, common algorithms, and small data-analysis building blocks.

![Python Files Progress](assets/python-files-bar.svg)

**Project Overview**

- **Purpose:** A day-by-day learning repository intended for learners to practice Python concepts and basic data-analytics patterns.
- **Primary language:** Python
- **Main content:** Lesson scripts and exercises organized under the `python/` folder.

**Repository Structure**

- `python/` — core lesson and exercise scripts (day-by-day).
- `assets/` — SVG assets used by this README (animated header and progress bar).

**How to use this repo**

1. Browse the `python/` folder to find the lesson or task you want to try.
2. Open a file in an editor or run it with the system Python interpreter (e.g., `python python/day1_inputMethods.py`).
3. Tweak inputs or add print statements to experiment interactively.
